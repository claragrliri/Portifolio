# Descrição do Portfólio📋

Página web de portfólio pessoal desenvolvida para apresentar minha trajetória, interesses em Web Design, Front-end e Mecatrônica, além de destacar minhas habilidades e projetos acadêmicos.

# 🔗Link do Site Publicado

Acesse o portfólio: :https://claragrliri.github.io/Portifolio/

# Tecnologias Utilizadas🛠️

HTML5 & CSS3: Estrutura e estilização visual.

Bootstrap 5: Responsividade e componentes de layout.

Devicon: Ícones de tecnologias.

Git & GitHub Pages: Versionamento e hospedagem.

# Explicação do Funcionamento⚙️

O site é estruturado em página única (Single Page) contendo:

Navbar: Menu superior fixo com navegação por links âncora.

Carousel: Área de destaque visual no topo.

Perfil: Apresentação pessoal, biografia, dados principais e ferramentas dominadas.

Projetos: Cards com imagens e descrições dos trabalhos realizados.

Contato: Canais de comunicação e redes sociais.

# Recurso Novo Adicionado✨

Efeitos de Hover e Rolagem Suave: Implementei animações de transição (transform: translateY e zoom nas imagens) ao passar o mouse sobre os cards, além da rolagem suave (scroll-behavior: smooth) para uma navegação mais fluida entre as seções.
